# 个人资源库比普通博客更重要

在信息可以被快速生成的环境里，收藏更多链接并不会自动形成优势。真正有价值的是你如何筛选、验证和重新使用这些信息。

## 按使用场景而不是平台分类

“来自 Midjourney”或“来自某个网站”不是最有用的分类。更好的方式是按产品图、品牌提案、批量内容、交付检查等场景组织，这样项目开始时可以直接找到入口。

## 每条资源都需要状态

记录来源、访问方式、授权范围、最后验证时间和适用边界。失效链接、来源不明的模型或无法解释授权的素材，不应该继续出现在公开资源库中。

## 资源必须连接实践

Prompt 模板应该链接使用它的工作流，检查清单应该链接实际案例。只有当资源帮助完成一次任务，它才从“收藏”变成了资产。

## 小而可信比大而失真更重要

资源库可以从两三项真正有效的内容开始。持续验证和复盘，比一次性铺满看似丰富的下载页更能建立信任。
