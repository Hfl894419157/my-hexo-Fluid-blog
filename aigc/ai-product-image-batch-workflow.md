      > **做品牌的朋友应该都有这个痛点，每到节日，就要出一张节日海报。 甚至于一年二十四个节气，每个节气，也都要重新想创意、重新出图，搞完一张海报半天没了，我最近研究了一套AI工作流，专门解决这个问题;**

      **先看成果：**

      ![image.png](/images/uploads/image.png)

      接下来，**我就拿24节气为例，带你走一遍完整流程。**

      > ***先说整体思路***

      很多人用AI做海报，上来就让AI直接出图，这导致的结果，**就是每次输出的海报，风格都不一样，缺少品牌调性。**

      > **问题出在哪？没有把流程拆开。**

      因为AI生图，之所以不一定符合品牌需求，++**要么是不了解品牌信息，要么是没有统一的视觉风格规范。**++

      > **所以，正确的思路是这样的：先定方向，再定规则，再做创意，最后出图：**

      ![7f2e039f44570f434794e6c24e3b0e1e.png](/images/uploads/7f2e039f44570f434794e6c24e3b0e1e.png)

      接下来，一步步地，带你拆解下这个工作流。

      ### **第一步：先明确品牌的视觉规范档案**

      **这一步只需要做一次，后续每次做品牌海报，都可以复用。**

      你需要准备这些东西：

      品牌Logo、产品图、标准色色号、行业描述、品牌关键词、目标受众、使用场景等：

      ![7ab4aaacf6c5620a690cb66faeb770b1.png](/images/uploads/7ab4aaacf6c5620a690cb66faeb770b1.png)

      然后把这些信息喂给AI，让它整理成一份品牌视觉资产档案。

      提示词如下，发给DeepSeek，直接用：

      ```
      你是一位品牌视觉档案管理师。请将我提供的企业信息整理成一份标准化的「品牌视觉资产档案」，供后续所有节气海报项目直接调用，无需重复填写。
      【企业基础信息】
      - 行业与主营业务：[填写]
      - 品牌核心关键词：[填写]
      - 标准色色号：[填写]
      - 目标受众：[填写]
      - 使用场景：[填写]
      【视觉参考方向】（如有，描述或附图）：[填写]
      请输出一份结构化的「品牌视觉资产档案」，包含以下模块：
      1. 品牌气质一句话定位
      2. 色彩体系（主色/辅色/禁用色/季节色彩倾向）
      3. 视觉风格标签（5个英文关键词，供AI出图使用）
      4. Logo使用规范（位置/大小/安全距离）
      5. 产品呈现偏好（融入场景/悬浮特写/有无产品）
      6. 文案风格偏好（语气/字数/中英文混排偏好）
      7. 明确禁止事项（不希望出现的元素、风格、颜色）输出格式为可存档的结构化文档，每项用简洁的规则语言描述，不超过2句话。
      ```

      这份档案整理好之后，可以收藏起来：

      ![image-1.png](/images/uploads/image-1.png)

      这一步输出的核心成果，就是品牌信息，简单点说，让AI了解品牌是干嘛的，别乱出图。

      ### 第二步：生成节气海报视觉规范

      有了品牌信息，下一步是准备节气海报视觉规范。

      **主要目的只有一个，就是在后续生图时，明确清楚，哪些东西，是24张海报必须保持一致，哪些东西可以随节气变化的。**

      比如像固定不变的，Logo位置、品牌色用法、构图框架、文案排版区域。允许变化的，季节色调、自然场景元素、光影氛围：

      ![image-2.png](/images/uploads/image-2.png)

      ```
      你是一位企业品牌视觉系统设计师。请基于以下品牌视觉资产档案，
      生成一份完整的「二十四节气海报视觉系统规则」，
      作为全年24张海报的统一执行标准。

      ——————————————————
      【品牌视觉资产档案】
      [粘贴第一步输出内容]
      ——————————————————
      【本年度创作基调补充】（如有）：[填写]
      【需重点打造的节气节点】（如有）：[填写]
      ——————————————————

      请输出以下模块，每项规则必须具体可执行，避免模糊描述：

      1. 全系列视觉主题：一句话定义本年度节气海报的整体创意方向
      2. 固定不变元素（每张海报必须保持一致）：
         - Logo位置与大小
         - 品牌色使用方式
         - 构图框架
         - 文案排版区域
      3. 允许变化的元素（体现节气差异）：
         - 季节色彩范围（按春夏秋冬分组）
         - 自然场景元素
         - 光影氛围
      4. 产品规范（如有产品）：
         - 产品在画面中的固定位置
         - 产品与节气场景的融合方式
      5. 文案规范：
         - 主标题格式
         - 副标题字数与语气
         - 禁用词汇或表达方式
      6. 出图关键词库（英文）：
         - 固定关键词（每张必须包含，约5个）
         - 季节关键词池（按春夏秋冬各列5个）
      ```

      这里面有一个点是要注意的，就是创作基调，简单来说，就是你希望24张海报，大体是啥样。

      **如果你想做无印良品那种风格，在创作基调里，不要只写简约风，这对AI来说太模糊了。**

      要这样描述：

      > **采用无印良品的风格基调，画面极度克制，大量留白，拒绝装饰性元素；色彩以低饱和米白、浅灰为主；构图偏向日式不对称留白美学，主体只占画面1/3；光线为漫射自然光，整体呈现柔和质感；材质偏好棉麻、陶瓷、原木。**

      这样出来的最终海报的风格基调，会保持一致：

      ![10cca671fbdc11edf00a6cf0f890648a.png](/images/uploads/10cca671fbdc11edf00a6cf0f890648a.png)

      当然，如果你不会描述，也可以让AI给你**反推描述信息，比如我们想要把整体基调，改为宋代美学：**

      ![image-3.png](/images/uploads/image-3.png)

      好了，这一步输出的内容中，**就会直接给到每次生图时，必须要加上哪些关键词：**

      ![image-4.png](/images/uploads/image-4.png)

      **这是风格一致性的主要保证：**

      ![06c00c87e9743c0def6c1866eea80a64.png](/images/uploads/06c00c87e9743c0def6c1866eea80a64.png)

      ### 第三步：24张创意批量策划

      当前面两步完成之后，那每一张海报大概长啥样呢？这时，++**就需要用AI来策划每一张海报的视觉画面。**++

      **我们可以把24个节气名称，一次性全部输入，让AI批量生成，每个节气海报的视觉策划方案。**

      提示词如下：

      ```
      你是一位企业节气海报创意总监。请基于以下视觉规则，
      为全部24个节气批量生成创意策划方案。

      【视觉系统规则文档】
      ——————————————————
      [粘贴第二步输出内容]
      ——————————————————
      【24个节气】
      立春、雨水、惊蛰、春分、清明、谷雨、
      立夏、小满、芒种、夏至、小暑、大暑、
      立秋、处暑、白露、秋分、寒露、霜降、
      立冬、小雪、大雪、冬至、小寒、大寒

      请为每一个节气输出以下内容，格式统一：
      ---
      【节气名称】
      - 核心创意方向（一句话，与品牌调性结合，避免常规联想）
      - 反直觉意象（1个，打破惯性思维的视觉切入点）
      - 画面结构（背景/主体/前景，各一句话）
      - 色彩方案（主色+辅色+光影氛围）
      - 产品呈现方式
      - 副标题文案建议（中文，不超过15字）
      - 出图关键词（英文，8～10个）
      ---
      注意：
      1. 同一季节的6个节气，创意方向必须有明显差异
      2. 优先用品牌调性关键词驱动创意，而非单纯描述自然景象
      3. 输出全部24个节气，不要省略
      ```

      这一步，输出的结果，就是24张节气海报的生图方向：

      ![image-5.png](/images/uploads/image-5.png)

      ### 第四步：直接出成品海报

      前三步都跑通之后，就可以生图了。

      **我使用的是chatgpt image 2，免费用户也可以每天生5张图：**

      ![image-6.png](/images/uploads/image-6.png)

      这一步，你要做的，就是把前面两步输出的内容（整体风格+生图关键词），**整合在一起，确保出图的稳定性。**

      提示词是这样的，把前面几步的内容，填进对应位置就行：

      ```
      你是一位专业的商业海报设计师，同时负责画面构图与文字排版。
      请根据以下所有规格，生成完整的品牌节气海报成品图提示词，
      画面与文字在同一张图中呈现。

      【产品保护指令——最高优先级】
      我已上传产品原图，请严格保持以下特征不变：
      - 产品外形与轮廓：必须与原图100%一致，不得改变造型
      - 产品颜色：必须与原图一致，不得偏色
      - 产品材质质感：必须与原图一致
      - 产品上的品牌标识：必须清晰可见，不得省略或变形
      - 产品比例：必须与原图一致，不得拉伸或压缩
      以上为最高优先级指令，场景可以变化，产品本身绝对不变。

      【画面规格】
      - 尺寸比例：3:4 竖版
      - 输出质量：超高清，商业印刷级别

      【品牌固定规则】
      [第二步输出内容填入]

      【本张海报 —— [节气名称]】
      [第三步输出内容填入]

      【文字排版规格】
      文字①——节气主标题
      - 内容：[节气名称，如"谷雨"]
      - 字体：宋体或细黑体，笔画纤细
      - 字号：画面高度的12%
      - 颜色：深炭灰 #2C2C2C
      - 位置：画面上方，距顶边15%，水平居中
      文字②——节气英文名
      - 内容：[节气英文名，如"Grain Rain"]
      - 字体：细无衬线英文，全大写
      - 字号：画面高度的2%
      - 颜色：中灰 #888888
      - 位置：主标题正下方，水平居中，字间距极宽
      文字③——副标题文案
      - 内容：[从第三步填入，如"雨落有声，万物生长"]
      - 字体：细宋体或细黑体
      - 字号：画面高度的3%
      - 颜色：深炭灰 #2C2C2C，透明度80%
      - 位置：画面下方，距底边20%，水平居中
      文字④——品牌名称
      - 内容：[品牌名，如"岚雾 LANWU"]
      - 字体：细无衬线体
      - 字号：画面高度的1.8%
      - 颜色：中灰 #888888
      - 位置：画面最底部，距底边5%，水平居中

      【Logo规格】
      - 使用上传的Logo原件
      - 位置：右下角，距底边和右边各留5%
      - 大小：画面宽度的10%～12%
      - 不得变色、变形、拉伸

      【严格禁止事项】
      ━━━━━━━━━━━━━━━━━━━━━━━━
      1. 除以上指定的四处文字外，不得出现额外文字
      2. 所有文字清晰可读，无笔画缺失、无错字
      3. 不添加水印、装饰边框、多余图形元素
      4. 整体保持呼吸感，画面不得拥挤
      ```

      这样，每次只需要替换节气名称、英文名、副标题文案，以及第三步对应的创意内容，其余保持不变。
