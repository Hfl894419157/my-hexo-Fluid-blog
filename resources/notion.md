# Notion 设计师项目管理模板

## 模板介绍

专为设计师打造的 Notion 项目管理模板，帮助你高效管理设计项目、客户和灵感。

### 核心功能

- 📋 项目看板管理
- 👥 客户关系管理
- 💡 灵感库 & Moodboard
- 📅 时间跟踪系统
- 💰 报价单生成
- 📊 数据统计面板

## 模板结构

### 1. 项目管理

**看板视图**：
- 待开始 → 进行中 → 审核中 → 已完成

**项目属性**：
- 项目名称、客户、截止日期
- 优先级、状态、标签
- 预算、实际成本

### 2. 客户管理

记录客户信息：
- 基本信息（联系方式、公司）
- 合作历史
- 沟通记录
- 待办事项

### 3. 灵感库

收集设计灵感：
- 图片画廊视图
- 标签分类（配色、排版、UI等）
- 来源链接
- 笔记备注

### 4. 时间跟踪

记录工作时长：
- 项目计时器
- 每日时间日志
- 月度统计报表
- 时薪计算

### 5. 文档资源

存储常用资源：
- 设计规范文档
- 合同模板
- 报价单模板
- 常用链接

## 下载使用

**Notion 模板链接**：[立即复制](https://notion.so/templates/designer-pm)

**使用步骤**：

1. 点击上方链接打开模板
2. 点击右上角"Duplicate"
3. 模板会复制到你的 Notion 工作区
4. 开始自定义使用！

## 快速上手

### 创建第一个项目

1. 进入"项目管理"页面
2. 点击"+ New"创建项目
3. 填写项目信息
4. 拖动卡片到"进行中"

### 添加客户信息

1. 进入"客户管理"数据库
2. 添加新客户
3. 关联到对应项目

### 收集灵感

1. 安装 Notion Web Clipper 插件
2. 浏览网页时一键保存
3. 自动添加到灵感库

## 自定义技巧

### 修改看板列

1. 进入"项目管理"
2. 点击"Status"属性
3. Edit property → 添加/删除状态

### 创建自定义视图

1. 在数据库右上角点击"+ Add a view"
2. 选择视图类型（Table、Gallery、Timeline）
3. 设置筛选和排序规则

### 添加关联数据库

```
/linked → 选择要关联的数据库
```

## 常见问题

**Q: 可以用手机管理吗？**  
A: 可以！Notion 有 iOS 和 Android 客户端。

**Q: 可以分享给客户查看吗？**  
A: 可以设置页面权限，分享给指定客户。

**Q: 数据会丢失吗？**  
A: Notion 自动云同步，无需担心数据丢失。
