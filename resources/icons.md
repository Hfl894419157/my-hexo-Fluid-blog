# 3D Glass Icons 玻璃图标包

## 资源介绍

C4D 玻璃图标源文件，包含 50+ 精美的 3D 玻璃质感图标，可自由编辑和渲染。

### 资源特点

- 💎 高品质玻璃材质
- 🎨 完全可编辑的 C4D 源文件
- 📦 多种文件格式导出
- ✨ 支持自定义颜色和光效

## 包含内容

### 图标分类

- **社交媒体**：微信、微博、抖音等 (12个)
- **工具应用**：设置、搜索、通知等 (15个)

## 使用教程

### 在 Cinema 4D 中使用

1. 打开 `.c4d` 源文件
2. 选择需要的图标对象
3. 调整材质颜色和透明度
4. 渲染并导出

### 快速使用（PNG）

直接使用预渲染的 PNG 图标：

- 分辨率：2048x2048 px
- 格式：透明背景 PNG
- 适用于：网页、UI设计、PPT等

## 自定义指南

### 修改颜色

1. 选中图标对象
2. 进入材质编辑器
3. 调整"玻璃"材质的颜色参数
4. 推荐使用 HSV 模式调色

### 调整光效

- **环境光**：影响整体亮度
- **点光源**：创建高光效果
- **反射强度**：控制玻璃反射程度

### 渲染设置

```
引擎：Octane Render / Arnold
采样：512-1024
分辨率：2048x2048 或更高
背景：Alpha 透明
```
